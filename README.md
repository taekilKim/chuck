# Chuck

문화 콘텐츠를 직접 끝까지 소비하지 않아도 전체 줄거리, 인물 관계, 복선, 반전, 연출·서술 장치, 결말과 해석까지 빠르게 이해하게 하는 웹 서비스 MVP입니다.

> 핵심 문장: **보고 싶은 콘텐츠와 알고 싶은 콘텐츠는 다르다.**

## 현재 상태

- 브랜드명: **Chuck**
- 이전 가제: 척척박사
- 형태: Web MVP
- Frontend: Next.js App Router
- Deployment: Vercel의 기존 `cheokcheok-doctor` 프로젝트
- Database / analytics: Supabase 연동 예정

## MVP 제1가설

사람들은 작품의 전체 내용을 알고 싶을 때 범용 GPT, 검색, 위키, 블로그, 유튜브를 돌아다니는 것보다 전체 줄거리·인물 관계·복선·반전·장치·결말·대화 포인트가 일정한 문법으로 편집된 완성된 작품 이해 페이지를 더 편리하게 느끼며, 한 작품을 본 뒤 다른 작품도 같은 방식으로 연속 탐색할 것이다.

가장 중요한 초기 지표는 **첫 작품을 본 사용자가 같은 세션 또는 재방문에서 두 번째 작품을 다시 검색하는 비율**입니다.
