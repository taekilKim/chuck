# Chuck — Decision Log

제품/기술 의사결정을 시간순으로 누적한다. 새로운 ChatGPT/Codex 세션에서는 `PROJECT_CONTEXT.md`와 함께 읽는다.

## 2026-08-19

### 브랜드

- 현재 서비스명은 **Chuck**으로 확정해 사용한다.
- 이전 가제 `척척박사`는 신규 UI/카피에서는 사용하지 않는다.
- 기존 Vercel 프로젝트 식별자 `cheokcheok-doctor`는 굳이 변경하지 않는다.

### MVP 플랫폼

- 네이티브 앱보다 **웹 MVP**를 먼저 만든다.
- 이유: 현재 검증하려는 것은 설치/알림/네이티브 기능이 아니라 `작품 이해 경험 → 다른 작품 반복 탐색`이기 때문이다.

### MVP 범위 축소

- 처음부터 모든 작품 검색을 지원하지 않아도 된다.
- 초기 작품을 제한해 결과 페이지 경험을 먼저 검증할 수 있다.
- 검색 결과가 없는 작품은 `아직 모르는 작품 / 요청하기` 상태로 처리할 수 있다.
- 복잡한 RAG, 전 작품 DB, Dark Catalog 운영 시스템을 제1가설 검증보다 먼저 구축하지 않는다.

### 기술 방향

- Next.js App Router 기반 웹
- Vercel 배포
- GitHub 저장소: `taekilKim/chuck`
- Vercel 프로젝트: 기존 `cheokcheok-doctor` 유지
- Supabase: 연동 예정. 초기 용도는 검색/행동 로그와 미등록 작품 요청 데이터이며 이후 콘텐츠 캐시/DB로 확장 가능

### 구현 우선순위

홈 화면보다 **좋은 작품 결과 페이지 한 개**가 더 중요하다. 결과 페이지가 사용자에게 충분한 가치를 주는지 확인한 뒤 검색/DB/콘텐츠 범위를 넓힌다.

### 컨텍스트 유지

- Google Drive의 기존 `척척박사 - 콘텐츠 압축 이해 서비스 기획서`를 GitHub의 `docs/PROJECT_CONTEXT.md`로 이전한다.
- Codex는 루트 `AGENTS.md`를 통해 이 컨텍스트와 결정 로그를 먼저 읽는다.
- 이후 중요한 제품/기술 결정은 이 파일에 계속 누적한다.
